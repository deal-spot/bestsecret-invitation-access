# BESTSECRET — multilingual invitation guide (GitHub Pages)

This is a complete **static website**, not a GitHub Gist. It includes `index.html`, 22 translated guide pages, `robots.txt`, and `sitemap.xml`. No build process, Node.js, or dependencies are needed.

## Publish the site correctly

1. Create a **public** GitHub repository named exactly `bestsecret-invitation-access` under the GitHub user `deal-spot`.
2. Extract this ZIP **before uploading**. Upload the actual files (`index.html`, `bestsecret-de.html`, etc.) into the repository **root**, not a nested folder. Commit to the `main` branch.
3. Open the repository's **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/(root)`, and save.
4. Wait for GitHub Pages to finish deploying. Open https://deal-spot.github.io/bestsecret-invitation-access/ and https://deal-spot.github.io/bestsecret-invitation-access/bestsecret-de.html.
5. If the URL is still 404, check the repo exists and is public, verify Settings → Pages and the **Actions** deployment log, and check that `index.html` is in the root.

## If your GitHub username or repository name differs

Replace `https://deal-spot.github.io/bestsecret-invitation-access/` in every HTML file, `sitemap.xml` and `robots.txt` with the actual published base URL **before upload**. The canonical and hreflang URLs must match your published site.
